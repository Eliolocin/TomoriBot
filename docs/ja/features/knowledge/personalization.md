TomoriBotは、`/personal`コマンドを使用して**あなた専用**に設定することができます。これらの設定は、サーバーの設定に関係なく、トモリと共有しているすべてのサーバーであなたに追従します。

## 個人の記憶

トモリが覚えているあなたに関する事実は、サーバー間で追従します。これらの管理（追加、削除、エクスポート）については、[メモリー](/ja/features/knowledge/memory/#個人とサーバーの記憶)のページで説明されています。

## プロフィールとペルソナ別の呼び名

`/personal profile about`では、性自認、代名詞、希望する呼び方をそれぞれ独立した任意項目として保存します。TomoriBotは、ある項目から別の項目を推測しません。希望する呼び方は、ペルソナの男性的・女性的・中立のバリエーションを選択します。既定では「中立」が選択されています。空欄の項目は消去され、プロンプトにも出力されません。生のプロフィール項目はプライバシーが「最小」の場合だけ使用されます。

`/personal profile nickname`は、全体またはペルソナ別のニックネーム、接頭辞、接尾辞を設定するモーダルです。ペルソナ別設定は安定した系統IDに従います。ニックネームはペルソナ別、全体、現在のDiscord表示名の順で継承されます。接頭辞と接尾辞も空欄なら同じ順で継承され、入力すればその値が優先されるため、Discord上のメンション対象を変えずに `マスターSparrowさん` のような表示を構成できます。ペルソナ自身が付ける敬称をやめてほしい場合は、ペルソナに直接伝えてください（「マスターと呼ばないで」など）。そのペルソナだけで無効になり、他のペルソナには影響しません。

サーバー管理者は`/persona naming-habits`でペルソナの既定値を設定できます。単独の呼びかけ語は整形済みの名前とは別で、ペルソナが作成するプロンプト文だけに使われます。既定で有効な「ユーザー情報の自動更新」機能は、会話中に明示された構造化変更をペルソナが適用できるようにします。無効にしても、2つの`/personal`コマンドは利用できます。

`/personal timezone`は-12から+14までの数値UTCオフセットだけを保存します。地域名やIANAタイムゾーンは保存・推測しません。

## 個人のプロバイダー

個人のプロバイダーを設定すると、*あなた自身のリクエスト*に対してサーバーのデフォルトではなく*あなた自身*のAPIキーとモデルを使用できるようになります。これは個人レベルでのBring-Your-Own-Key（BYOK）です。

2つのスコープを区別しておくと分かりやすくなります。

- **サーバー既定**：1つのサーバー共通の設定です。必要な権限を持つメンバーが`/provider`と`/model`で管理し、そのサーバーの全員に適用されます。
- **個人上書き**：あなた自身のリクエストにのみ使われる設定です。有効にすると、設定したサーバーだけでなく、TomoriBotを使う**すべてのサーバー**でその機能のサーバー既定を上書きします。

**セットアップ:**

1. `/personal provider add`でプロバイダーを保存します（APIキーは暗号化されます）。同時に、そのプロバイダーの既定テキストモデルで個人の**テキスト**上書きが有効になります。
2. `/personal provider model-text`は任意です。手順1で選ばれた既定モデル以外を使いたい場合にのみ使用します。ここでモデルを選んでもテキストは有効なままです。
3. `/personal provider toggle-models`で機能ごと（テキスト、埋め込み、画像、動画、ビジョン）に上書きを有効化・無効化します。

手順3はモデルを選ぶたびに必要になるわけではありません。`/personal provider model-*`でモデルを選んだ時点でその機能は有効になります。トグルコマンドは、機能を**オフ**にして各サーバーの既定に戻すためのものです。

機能をオフにしても、それを担当していたプロバイダーは記憶されます。そのため再びオンにすると、最初に保存したプロバイダーではなく、元の同じプロバイダーに戻ります。

手順1と2はサーバー横断の上書きへ切り替える操作なので、機能がサーバー既定から個人上書きへ変わる場合は保存前に確認が表示されます。すでにあなたのリクエストに使われているプロバイダーのキーを更新するだけならルーティングは変わらないため、確認は省略されます。

思考ログはそれらのターンをあなたに帰属させ、`/personal parameters`と`/personal model fallback`で調整できます。どちらも全サーバーであなたのリクエストにのみ影響し、このサーバーの設定は変更しません。また、`/personal custom-endpoint add`で個人のカスタムエンドポイントを登録することもできます。[カスタムエンドポイント](/ja/features/setup-administration/providers-and-models/#custom-endpoints)を参照してください。

個人のプロバイダーを使用中にリクエストが失敗した場合、エラーの「できること」ヒントには、サーバー管理者向けコマンドではなく実際に対処できる個人向けコマンド（`/personal provider model-text`、`/personal model fallback`、`/personal parameters`）が表示されます。`/personal provider toggle-models`で**テキスト**をオフにすれば通常はサーバーのモデルに戻せますが、User BYOKモードのサーバーでは引き続き個人プロバイダーが必要です。

:::note[BYOK必須サーバー]
サーバーはUser BYOKモード（[サーバーモデレーション](/ja/features/setup-administration/server-moderation/#user-byok-bring-your-own-key)）を使用して、メンバー提供のプロバイダーを必須にすることができます。これがオンの場合、あなたがトリガーしたメッセージにトモリが応答するには個人のプロバイダーが必要です。個人のプロバイダーは、トモリを使用するすべてのサーバーに適用されます。
:::

## その他の個人設定

- `/personal profile nickname`：トモリからの呼ばれ方を変更します。
- `/personal image-tags`：ご自身の外見タグ（booruスタイル）。[画像生成](/ja/features/capabilities/media-generation/image-generation/#tag-customization)であなたが参照された場合に使用されます。空欄で送信するとクリアされます。
- `/personal privacy`：トモリに対する可視性を制御します。**完全な不可視**（メモリー機能を完全にオプトアウト）まで設定可能です。
- `/personal dtm`：[意図的トリガーモード](/ja/features/chatting-personality/chatting-and-triggers/#意図的トリガーモード)の個人用の上書き設定です。
- `/personal stm`：サーバー間の短期記憶の共有をオプトインします。`/personal stm clear`でSTMを消去します。
- `/personal impersonate prompt`：トモリが`/bot impersonate`であなたを模倣する際の再利用可能なプロンプトを設定します。
  
## パーソナルスポットライト

**パーソナルスポットライト：チャンネル別のペルソナ選択。**スポットライトを使用すると、あるチャンネルでトリガーできるペルソナを*あなただけ*絞り込むことができ、任意でそのチャンネルでのご自身のメッセージに対するオートトリガーペルソナを割り当てることもできます。これは**あなた＋1つのチャンネル**にスコープされており、他の人には影響しません。

`/personal spotlight set`で**設定**し、以下を選択します：

- 期間（時間単位。手動で削除するまで保持するには**0**を使用します）
- ターゲットチャンネル
- スポットライトに含めたいペルソナ

ペルソナを選択した後、任意で**パーソナルオートトリガーペルソナ**（そのチャンネルでのご自身のメッセージに対するフォールバックの応答者）を1つ選択できます。直接的なトリガーは、依然としてあなたが明示的に呼び出したペルソナを対象とします。「Finish」を押すとスキップできます。

**重要なルール：**

- スポットライトはアクセスを**絞り込む**だけで、拡大することはありません。選択したペルソナは、そこでトリガーできる*唯一*のペルソナになります。
- `/server whitelist persona`などのサーバーレベルの制限は引き続き尊重されます。
- プロキシチェーンはブロックされます。あなたのスポットライトにAliceのみが含まれている場合、Aliceの返信があなたのメッセージチェーンのためにBobに引き継ぐことはできません。

`/personal spotlight manage`でエントリを確認または削除できます（チェックを外すと削除されます。期限付きのスポットライトは自動的に失効します）。Discordでは`/help`の **動作** から **個人スポットライト** を開くと概要を確認できます。
